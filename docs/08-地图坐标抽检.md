# 08 — 地图坐标对齐抽检（A3）

> 日期：2026-09-20  
> 相关：`docs/06` A3、`src/lib/pubg/maps.ts`、`src/lib/pubg/map-coords.ts`、`match-replay.tsx`

## 1. 约定

| 项       | 值                                                        |
|---------|----------------------------------------------------------|
| 遥测单位    | 厘米（cm）                                                   |
| Erangel | `Baltic_Main` / `Island_Main`，`sizeCm = 816000`（8×8 km）  |
| Sanhok  | `Savage_Main`，`sizeCm = 408000`（4×4 km）                  |
| 轴方向     | **x → 右，y → 下**；画布 **无 Y 翻转**（与官方 api-assets 顶视一致）       |
| 归一      | `nx = x / sizeCm`，`ny = y / sizeCm`                      |
| 底图像素    | `px = nx * imgW`，`py = ny * imgH`（本仓库 Low_Res ≈ 819×819） |
| 回放投影    | `telemetryToCanvas`（全图居中 zoom=1 时：原点 → 画布左上，中心 → 画布中心）   |

## 2. 可复现命令

```bash
# 仓库根目录；无外网、不依赖 .data/telemetry
node scripts/check-map-coords.mjs
```

期望末行：`A3 坐标对齐抽检：通过`，进程退出码 `0`。

脚本覆盖：

1. `mapSizeCm` 与 `public/maps/{erangel,sanhok}.png` 尺寸读取
2. 四角 + 中心：cm → 归一 → 图像素 / 画布
3. Y 轴单调（增大 y → 增大 cy）
4. `drawImage` 全图源矩形 `sx=sy=0, sw=imgW`
5. Erangel 已知 POI（Pochinki / School / Military / Georgopol / Primorsk / Novo）落在约定象限
6. 社区 8192px → cm → Low_Res 比例闭环

## 4. 人工目视（可选，约 2 分钟）

本机无 `.data/telemetry` 时跳过；有对局时：

1. `npm run dev` → 打开 Erangel / Sanhok 对局 →「回放」Tab
2. 全图 zoom=1：轨迹不应整体镜像；南岛 Military / 西岸 Georgopol 相对方位应与底图标注一致
3. 地图中心 `/maps/erangel`：POI 点应落在对应城镇附近（近似，非像素级）

验收：`脚本已跑通过` +（有遥测时）`人工看回放约 2 分钟无镜像/错图`。

## 5. 失败时排查

| 现象           | 可能原因                                         |
|--------------|----------------------------------------------|
| POI 整体上下颠倒   | 错误加了 `1 - ny`；应保持 y 向下                       |
| Sanhok 点挤在一角 | 误用 816000 边长                                 |
| 底图拉伸错位       | `drawImage` 的 sx/sy 与 `toCanvas` 中心/zoom 不一致 |
| 仅社区密室偏一点     | 社区清单近似 + `Math.round`；非映射 bug                |
